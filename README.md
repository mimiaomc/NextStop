# NextStop (下一站)

NextStop 是一款基于 **GTK4 + Libadwaita** 的可定制化公交与轨道交通报站器模拟器。

支持自由组合站点广播、到站提示、地铁换乘预告、沿途广告插播以及车外进站广播，支持自定义语音包扩展。

## 特色功能
- **模块化广播拼装**：严格还原真实公交报站逻辑（首站启程、途中站前提醒、下一站预告、换乘提醒、进站提示音与到站广播、终点站双重广播）。
- **语音包扩展**：支持多城市、多系统、多播音员（公交、地铁、不同时期配音版本）自由切换。
- **现代化 GNOME 界面**：采用 GTK4 / Libadwaita 原生设计。

## 运行与开发

推荐使用 **GNOME Builder** 直接打开本项目目录，点击顶部的运行按钮 ▶ 即可在 Flatpak 沙箱环境中一键构建运行。
